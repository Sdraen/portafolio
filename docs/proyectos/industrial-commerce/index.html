01 / EL DESAFÍO

Entender antes de construir.

El comercio industrial necesita mostrar información técnica sin convertir la compra en un proceso pesado. El desafío fue reunir catálogo, cotizaciones y checkout en una experiencia coherente, y al mismo tiempo ofrecer una forma segura de demostrar la administración del sistema.

02 / LA SOLUCIÓN

Un producto completo, no solo una interfaz.

Diseñé dos caras conectadas del producto: una tienda enfocada en explorar y convertir, y un panel administrativo que permite comprender la operación sin exponer acciones destructivas en la demostración pública.

  • Catálogo de productos y navegación orientada a compra
  • Flujos diferenciados para checkout y solicitudes de cotización
  • Panel administrativo público con acceso de solo lectura
  • Arquitectura full-stack con datos y lógica de negocio integrados
03 / EL RESULTADO

Una base útil y preparada para evolucionar.

El resultado es una demostración funcional que permite evaluar tanto la experiencia del cliente como la operación interna. El proyecto muestra cómo abordo producto, interfaz, backend y datos como un solo sistema.
